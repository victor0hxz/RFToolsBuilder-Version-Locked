## Installation

Download `rftoolsbuilder-26.1.2-8.0.0-atm11.jar` from [Releases](https://github.com/victor0hxz/RFToolsBuilder-Version-Locked/releases). Requirements: Matching McJtyLib and RFTools Base ATM11 builds; NeoForge 26.1.2.109; Java 25. Replace older copies of the same mod; the mod ID is preserved, so do not install this build alongside another copy of the same mod. Use matching versions of McJtyLib and the RFTools modules.

## Validation and limitations

Previously compiled Java 25 artifact found installed in the ATM11 instance and listed in its mod inventory. ZIP integrity, mod metadata and bytecode version verified. Full gameplay functionality was not retested during publication. The exact modified source tree was not located in the inspected folders.

The JAR contains the same production class bytes and resources as the installed artifact; publication only adds the original MIT license notice. Builder and Dimensions retain inherited older dependency declarations in their metadata, which were not corrected or retested in this distribution step. These are prereleases for further compatibility testing, not a guarantee that every machine or dimension workflow has been validated.

## Source availability

This repository contains audited binaries and [Java source reconstructed from the published JAR](recovered-source). The exact original modified source tree was not located. The recovered code is explicitly decompiled, and recompilation has not been verified.
